<h1 align="center">TekStore - проект интернет магазина для вуза</h1>

## Description

TechStore - это современный многостраничный веб-сайт интернет-магазина техники и флагманских гаджетов. Сайт разработан на чистом семантическом HTML5 и CSS3 с базовым БЭМ-именованием классов, без использования сторонних CSS-фреймворков. Проект спроектирован как основа для последующих контрольных работ (КР №3 - адаптивность, КР №4 - расширенный JS, КР №5 - переход на SPA React/Vue).

## Architecture

```text
kr1-html-css-shop/
├── index.html       # Главная страница: hero-блок, преимущества, популярные товары
├── catalog.html     # Каталог: карточки товаров, категории, фильтры

├── js/
│   └── main.js      # Минимальная логика модального окна <dialog> и уведомлений
├── images/          # Графические ресурсы проекта (SVG векторные иконки)
├── .gitignore       # Игнорируемые файлы Git (node_modules, .DS_Store и т.д.)
```

## Stack

- **HTML5:** Семантические теги (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<dialog>`, `<table>`, `<form>`).
- **CSS3:** 
  - CSS-переменные в блоке `:root` (палитра цветов, отступы, радиусы, тени);
  - Методология БЭМ (`site-header__logo`, `product-card--hit`, `order-form__input`);
  - Раскладки на Flexbox и CSS Grid;
  - Позиционирование: `relative`, `absolute`, `sticky`, `fixed`, `z-index`;
  - Состояния элементов: `:hover`, `:focus-visible`, `button:disabled`.
- **JavaScript (Vanilla JS):** Открытие/закрытие модального окна `<dialog>`, плавный возврат наверх страницы, валидация полей формы.

## Page`s decsription

1. **index.html** — Главная страница. Включает промо-баннер (hero), блок преимуществ с якорной ссылкой `#advantages`, витрину хитов продаж (`#popular`), баннер с переходом к контактам (`#contacts`).
2. **catalog.html** — Каталог товаров. Содержит боковую панель фильтров (`<aside class="filter-panel">`), панель сортировки, сетку товаров на CSS Grid и постраничную навигацию.
3. **product.html** — Детальная страница товара. Содержит фотогалерею, выбор конфигурации, кнопку вызова модального окна быстрого заказа и подробную таблицу сравнительных характеристик модельного ряда.
4. **order.html** — Форма заказа. Включает поля: имя, email (`type="email"`), телефон (`type="tel"`), выпадающий список товара (`<select>`), комментарий (`<textarea>`), чекбокс согласия на обработку персональных данных (`required`).
5. **contacts.html** — Контактный центр. Карточки адресов, телефоны, график работы, стилизованная схема проезда и форма обратной связи.
